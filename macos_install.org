* Get Dot Files
** Create An SSH Key
- set a passphrase: it's saved in the keychain below, so it's only typed once

#+begin_src shell
ssh-keygen -t ed25519 -C "your_email@example.com"
#+end_src

** Save The Passphrase In The Apple Keychain
- run once; the keychain keeps it across reboots
- after the first switch, =~/.ssh/config= (=programs.ssh= in =nix/home.nix=)
  sets =UseKeychain= and =AddKeysToAgent=, so ssh loads the key into the
  agent on first use without prompting

  #+begin_src shell
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
  #+end_src

** Add Key To Github
- copy the public key:
  #+begin_src shell
pbcopy < ~/.ssh/id_ed25519.pub
  #+end_src
- add it to GitHub: =Settings= -> =SSH and GPG keys= -> =New SSH Key=
- test with:
  #+begin_src shell
ssh -T git@github.com
  #+end_src

* Homebrew
nix-darwin manages Homebrew packages (=homebrew.*= in =nix/darwin.nix=) but
doesn't install Homebrew itself.

** Install
- follow the [[https://brew.sh][website's]] instructions

** Disable Analytics
#+begin_src sh
/opt/homebrew/bin/brew analytics off
#+end_src

* Nix, nix-darwin and home-manager
Everything else comes from the flake in this repo:
- =nix/darwin.nix= :: the machine: Nix settings, macOS defaults, Touch ID
  sudo, fish as a system shell, and the Homebrew list (~cleanup =
  "uninstall"~, so anything not listed gets removed)
- =nix/home.nix= :: the user (home-manager): CLI tools, fish config, git,
  starship, direnv and other dotfiles

** Install Nix
- use the upstream [[https://github.com/NixOS/nix-installer][NixOS/nix-installer]]
  (not the Determinate one)

** First Switch
=darwin-rebuild= doesn't exist yet, so run it from the nix-darwin flake. The
flake output is named after the hostname (=Seans-MacBook-Pro=).

#+begin_src sh
sudo nix run nix-darwin/master#darwin-rebuild -- switch --flake ~/.dotfiles
#+end_src

If it stops with "Unexpected files in /etc", move each listed file aside
(e.g. =sudo mv /etc/shells /etc/shells.before-nix-darwin=) and run it again.

If home-manager stops with "would be clobbered", the file is a symlink it
didn't create: delete the symlink and switch again. (Regular files are moved
aside automatically as =*.before-home-manager=.)

** Make Fish The Login Shell
Then log out and back in.

#+begin_src sh
chsh -s /run/current-system/sw/bin/fish
#+end_src

** Day To Day
#+begin_src sh
# after editing anything under nix/ (new files must be git added first)
nix build ~/.dotfiles#darwinConfigurations.Seans-MacBook-Pro.system --no-link
sudo darwin-rebuild switch --flake ~/.dotfiles

# update nixpkgs, nix-darwin and home-manager
nix flake update
#+end_src

* iTerm2 Configuration
- Set the font
- Set =Profile= > =Keys= > =Left Option Key= to =ESC+=
- Set =Profile= > =Keys= > =Right Option Key= to =ESC+=

* Window Management
Managed by nix-darwin: rift (tiling) and JankyBorders (focus borders) are
configured in =nix/window-management.nix=.

* Rust
** Install A Toolchain
=rustup= comes from =home.packages= (no curl installer, no =~/.cargo/env=).
After the first switch:
#+begin_src sh
rustup default stable
rustup component add rust-analyzer
#+end_src

=~/.cargo/bin= is on PATH via =home.sessionPath= for =cargo install= tools.
Projects use per-project flakes (rust-overlay) for their toolchains.
